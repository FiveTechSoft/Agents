Agents ? What's new
===================

v2.5.0 (2026-07-18)
-------------------
* Token usage with Ollama: request stream_options.include_usage and normalize
  OpenAI + Ollama eval counts so the footer shows real consumption.
* Footer status line: "> Esc interrupt" + centered rotating tip + abbreviated
  usage chip "in:3.5K out:49 Σ3.5K 2.9s" (replaces bare "0" and the long
  transcript token bar).
* Tips no longer spam the transcript after every turn — one tip on the footer.
* Thinking status: single in-place row; fixed header before ⎿ block; no
  indented ghost Thinking after clear.
* Misc transcript polish carried from 2.4.9 line (clock, Build chip, spacing).

v2.4.9 (2026-07-18)
-------------------
* FIX reply clock: align with user prompt (UTF-8 visual width); clock only
  on the last line; hold last line instead of cursor-up restamp (that
  duplicated the "□ Build · model" chip).
* FIX stacked status rows: single Thinking line that repaints in place;
  no "Working" flash before Thinking.
* FIX blank gap between Tip and "Worked for"; fewer empty rows after
  Thought for when the model sends only whitespace.
* FIX scroll region: box rows stay outside VT scroll so Build chip is not
  scrolled into the transcript.
* Footer: "> Esc interrupt" instead of dotted "esc interrupt".

v2.4.8 (2026-07-18)
-------------------
* FIX curl exit 23 false error: treat CURLE_WRITE_ERROR as benign when the
  stream body was already received; kill curl before closing the pipe on
  intentional silence end so broken-pipe noise is avoided.
* FIX thinking body alignment: ⎿ under the "T" of Thinking (card pad was
  shifting it under the "i"); single space after the corner glyph.
* FIX assistant reply truncation: long first lines no longer end in
  "...  10:34 AM" — text word-wraps to the next line with the clock on the
  first visual row when it fits.

v2.4.7 (2026-07-17)
-------------------
* FIX space bar dropped while typing: the box editor guarded the insert
  with !Empty(cCh), and Empty(" ") is .T. in Harbour, so the space key
  (codepoint 32) mapped correctly then got discarded -- multi-word prompts
  were impossible. Guard on Len() now.
* FIX queued slash commands: a /exit, /save or /clear typed while the model
  was answering went to the model as a chat message instead of executing.
  The post-turn drain now re-parses each queued line and runs commands
  through the normal command path.

v2.4.6 (2026-07-17)
-------------------
* FIX interactive freeze: Inkey(0.001) still blocked forever (Harbour clamps
  sub-centisecond timeouts to infinite in hb_gt_def_InkeyGet); the first
  keyboard poll of every turn hung before curl was spawned. Non-blocking
  polls now use Inkey( , mask ); AGCON_WaitKey floors its timeout at 0.01s.
* FIX /plan crash: comparing the PeekNamedPipe/GetExitCodeProcess dynCall
  result against a number threw BASE/1 Argument error when the pipe closed;
  killed the whole session on /plan. Type-safe AGHTTP_DynBool() now.
* /plan and /compact show the animated Working status (heartbeat) instead of
  waiting silently on reasoning models; runtime errors there no longer exit.
* Rendering cleanups: single status row per turn (no stale spinner rows),
  status suspend/resume around mid-turn [pending] prints, clock only on the
  first line of a reply, deferred trailing blank lines, "Worked for Ns"
  instead of a duplicated model chip, footer no longer truncated to "/he".

v2.4.0 (2026-07-17)
-------------------
* OpenCode layout (opencode1.jpg): amber [•]/[ ] todos, amber "Thinking",
  "Build · model" chip, footer "esc interrupt · tokens · /help".

v2.3.1 (2026-07-17)
-------------------
* Grok6 transcript: user bar + AM/PM clock, "♦ Read 1 file" activity lines,
  "| Thinking… 13s" status with elapsed, full-width green/red diffs,
  plain assistant text with clock, "Worked for 2m5s."

v2.2.1 (2026-07-17)
-------------------
* Grok Build task panel (from grok2.jpg): full-width slate rows with green
  ✓ for completed todos; badge N/M on the prompt status line; keep the
  panel visible after every item is done.

v2.2.0 (2026-07-17)
-------------------
* Grok Build turn model (from grok1.jpg): gray "> message" bar + 6:31 AM
  clock, Waiting for response…, diamond (♦) thought/tool lines, footer
  "Worked for 2m17s."

v2.1.2 (2026-07-17)
-------------------
* Mid-turn queue: type while the model is answering; the line shows as
  [pending] / badge "pending xN", then runs after the current reply
  (e.g. "Hola" then "quien eres ?" without waiting for the first answer).
* Fix keyboard poll: Inkey(0) blocked forever and deadlocked curl mid-stream;
  non-blocking poll restores typing during a turn.

v2.1.1 (2026-07-16)
-------------------
* Default backend: if no API key is set, detect a running local Ollama
  server and use its default/first model (same as /provider ollama).
* Single Enter submits slash commands (/exit, /help, …); no hang after CR.

v2.1.0 (2026-07-16)
-------------------
* /help reliable in prompt box (parse + pin/redraw).
* /exit, /quit, /bye leave cleanly with [bye]; aliases without slash work too.

v2.0.0 (2026-07-16)
-------------------
* Harbour-standard keyboard (Inkey + hb_keyStd/hb_keyChar); prompt typing fixed on WSL.
* Linux: gttrm + static binary at repo root (./agents, ./go.sh).
* Repo layout: source/, android/, scripts/, screenshots/; binaries at root.
* /demo — full random offline session (cards + most commands, no API).
* /help — full command list.
* settings.json gitignored; use settings.example.json + /provider key or env.
