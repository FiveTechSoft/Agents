Agents

Version 1.0

Agents EXE

Native desktop executable built with Harbour and FiveWin. A full TUI (Terminal User Interface) coding assistant with streaming SSE, 17 built-in tools, skills system, multi-agent dispatch, and a persistent input box — all in a single ~1.2 MB executable. No Python, Node.js, or Docker required.

Architecture

graph TD A[agents.exe] --> B[REPL Loop] B --> C[Agent Class] C --> D[Streaming API] C --> E[Tool Registry] C --> F[Skills System] D --> G[curl SSE] E --> H[17 tools] F --> I[.agents/skills/] B --> J[TUI Layer] J --> K[Input Box] J --> L[Markdown Cards] J --> M[Permission Gate]

Features

  • Single executable: ~1.2 MB, zero dependencies
  • Full TUI: Card-style output, persistent multi-line input box, markdown rendering
  • Streaming SSE: Real-time token-by-token via curl subprocess
  • 17 Built-in Tools: read, write, edit, glob, grep, shell, web_search, web_fetch, github_read, github_write, memory, ask_user, todo_write, use_skill, dispatch_agent, dispatch_agent_background, propose_agents
  • Slash Commands: /help, /model, /plan, /goal, /run, /key, /provider, /clear, /save, /load, /lean, /compact, /rewind, /loop, /tasks, /btw, /hook, /caveman
  • Skills System: Markdown-based with YAML frontmatter, auto-activation via trigger regex
  • Multi-Agent: dispatch_agent (blocking) and dispatch_agent_background (threaded)
  • Permission Gate: allow/deny/ask per tool + plan-mode lock
  • Session Management: /save and /load with JSON export
  • Multi-Backend: DeepSeek, OpenAI, GLM, Moonshot, Ollama

Building from Source

cd agents\source
hbmk2 -comp=msvc64 agents.hbp

Requires: Harbour 3.2+, Visual Studio 2019/2022 Build Tools, curl (included in Windows 10/11).

Quick Start

# Set your API key
set DEEPSEEK_API_KEY=sk-...

# Launch
agents.exe

# Or specify a backend
agents.exe
/provider deepseek
/key sk-...

CLASS Agent API

The Agent class is a reusable OOP wrapper for autonomous AI agent loops with tool-calling, skills, planning, and multi-agent dispatch.

Initialization

oAgent := Agent():New( cApiKey, cModel, hOpts )
// hOpts: { base_url, max_steps, timeout, co_author, github_token, interrupt, inject }

Main Loop

MethodDescription
Run( cPrompt )Execute full agent loop with prompt, returns { success, content, stop_reason, iterations, tool_call_count, usage }
Step()Single LLM API call with streaming SSE
AddMessage( cRole, cContent )Append to conversation history
BuildSystemPrompt()Compile system prompt with skills + tools

Skills

MethodDescription

DeactivateSkill( cName )Disable a named skill

Complete Example

#include "hbclass.ch"

FUNCTION Main()
   LOCAL oAgent, hResult

   oAgent := Agent():New( hb_GetEnv( "DEEPSEEK_API_KEY" ), ;
      "deepseek-v4-pro", { "base_url" => "https://api.deepseek.com" } )

   hResult := oAgent:Run( "List all .prg files and summarize each in one line" )

   IF hResult[ "success" ]
      ? hResult[ "content" ]
      ? "Steps:", hResult[ "iterations" ]
      ? "Cost: $", oAgent:UsageReport()
   ENDIF

RETURN 0
