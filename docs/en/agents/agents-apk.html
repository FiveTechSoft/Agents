Agents APK

Android mobile package running the full Agents engine natively on ARM devices. Built with Harbour cross-compiled to Android NDK, wrapped in an APK with a WebView-based chat UI.

Architecture

graph TD A[Android APK] --> B[WebView UI] B --> C[Agents Engine] C --> D[Harbour Runtime] C --> E[Agent Class] E --> F[Tools] E --> G[API Client] G --> H[DeepSeek / Ollama]

Features

  • Native ARM: Harbour compiled for Android NDK, no emulation
  • WebView UI: HTML5 chat interface inside Android WebView
  • Offline-capable: Connect to local Ollama or on-device models
  • Same tools: All 17 built-in tools available (filesystem access via Android scoped storage)
  • Permissions: Android runtime permissions for storage, network, shell

Building APK

# Cross-compile Harbour for Android NDK
export HARBOUR=/opt/harbour-android
export NDK=/opt/android-ndk

# Build native library
hbmk2 -comp=android agents_android.hbp

# Package as APK with Android Studio / Gradle
./gradlew assembleRelease

Installation

# Install via ADB
adb install agents.apk

# Or sideload from device storage
# Settings → Security → Unknown sources → Allow
# Open agents.apk from Downloads
