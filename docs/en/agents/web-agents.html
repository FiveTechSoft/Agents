Web Agents

An AI agent that runs entirely in your browser as a static HTML5/JS app (GitHub Pages) — no server required. It works on a virtual disk (IndexedDB), runs real WASM runtimes, and connects to cloud LLM APIs. Default model: Ox Alpha (x-preview-f-free) via the OpenCode Zen API — free, no API key — with automatic fallback to other free OpenCode models when unavailable (mimo-v2.5-free, DeepSeek Flash, Hy3, Nemotron, Laguna).

Architecture

Features

  • Zero-install: Runs in any modern browser or embedded WebView2 control (~500 KB HTML+JS+Wasm)
  • Cloud AI: OpenCode Zen (Ox Alpha default) with dynamic discovery of free models and automatic retry/fallback
  • Streaming SSE: Real-time token-by-token streaming responses, including live reasoning content (thinking mode)
  • 21 Built-in Tools: see the table below
  • Real runtimes in WASM: Python (Pyodide), C (clang/Wasmer), PHP 8 (@php-wasm with web preview of .php pages), SQLite (SQL on virtual .db files)
  • Skills System: Markdown skills injected into the system prompt; created/toggled by the agent itself or via /skill
  • User-defined tools: register_tool lets the agent create new callable commands from scripts on disk; they persist in localStorage
  • Persistent memory: remember tool writes durable facts to MEMORY.md, available in future sessions (/memory, /distill)
  • Scheduled tasks: recurring prompts/commands every N minutes/hours/days while the page is open (/cron, schedule_task tool)
  • SSH gateway: connect to remote servers over WebSocket→TCP (ssh2)
  • Voice: TTS reads the replies aloud; pick a voice with /voice
  • Multi-Agent Dispatch: dispatch_agents runs 2–4 subagents in parallel around a shared contract
  • Permission Gate: allow/deny/ask per tool via /perm
  • Sessions: persist across reloads; export to Markdown (/export), shareable read-only links (/share)
  • PWA: installable web app (manifest.webmanifest)

Quick Start

// The agent discovers free models from OpenCode Zen at startup
// and always tries Ox Alpha first — no API key required
const agent = new Agent({
  model: 'x-preview-f-free',              // Ox Alpha Free
  baseUrl: 'https://api.fivetechsoft.com/zen/v1',   // OpenCode Zen via fivetechsoft.com
  apiKey: 'public',
  fallbackModels: await discoverFreeModels()
});

Free Models & Dynamic Fallback

Web Agents query the OpenCode Zen endpoint GET /models at startup to dynamically discover which free models are available (ids ending in -free). The retry order always starts with Ox Alpha (x-preview-f-free), then Mimo (mimo-v2.5-free), followed by the remaining free models as reported by the API:

// Discover free models from OpenCode Zen, ordered by preference
async function discoverFreeModels() {
  const PREFERRED = ['x-preview-f-free', 'mimo-v2.5-free']; // Ox Alpha, Mimo
  const res = await fetch('https://api.fivetechsoft.com/zen/v1/models', {
    headers: { 'Authorization': 'Bearer public' }
  });
  const { data } = await res.json();
  const free = data.map(m => m.id).filter(id => id.endsWith('-free'));
  // Preferred models first, remaining free models by availability
  return [
    ...PREFERRED.filter(id => free.includes(id)),
    ...free.filter(id => !PREFERRED.includes(id))
  ];
}

If a request fails (rate limit, upstream error, timeout), the Agent automatically retries with the next model in the list.

FiveWin TWebView2 Integration

Web Agents integrate natively with FiveWin's TWebView2 class, providing a full chat UI inside desktop applications:

#include "FiveWin.ch"

FUNCTION Main()
   LOCAL oWnd, oView
   DEFINE WINDOW oWnd TITLE "Agents - Web Agent"
   oView := TWebView2():New( oWnd )
   oView:Navigate( "agents/web/index.html" )
   ACTIVATE WINDOW oWnd CENTERED
RETURN NIL

AI Disk Classifier

Web Agents include an AI disk classifier powered by transformers.js — classify files on the virtual disk using local AI models without sending data to any cloud service.

// Classify files on the disk
const result = await agent.run(
  'Classify all files by type (source, config, doc, asset)'
);
