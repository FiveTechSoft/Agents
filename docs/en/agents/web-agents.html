Web Agents

Agents that run entirely in the browser using WebView2 or as standalone HTML5/JS applications. No server required — the AI agent logic runs client-side with transformers.js or connects to cloud APIs (OpenCode Ox Alpha, DeepSeek, OpenAI, Ollama). Default model: Ox Alpha (x-preview-f-free) via the OpenCode Zen API — free, no API key — with automatic fallback to the other free OpenCode models when unavailable.

Architecture

Features

  • Zero-install: Runs in any modern browser or embedded WebView2 control
  • Local AI: Transformer.js for on-device inference (no cloud required)
  • Cloud AI: Connects to OpenCode (Ox Alpha), DeepSeek, OpenAI, Ollama, or any OpenAI-compatible API
  • Streaming SSE: Real-time token-by-token streaming responses
  • 17 Built-in Tools: read, write, edit, glob, grep, shell, web_search, web_fetch, github_read, github_write, memory, ask_user, todo_write, use_skill, dispatch_agent, dispatch_agent_background, propose_agents
  • Skills System: Markdown-based skill files with YAML frontmatter, auto-activation via trigger regex
  • Multi-Agent Dispatch: Spawn subagents (blocking or background) for parallel task execution
  • Permission Gate: allow/deny/ask per tool with plan-mode lock

Quick Start

// Create a Web Agent powered by Ox Alpha (OpenCode Zen)
// https://github.com/anomalyco/opencode — no API key required
const agent = new Agent({
  model: 'x-preview-f-free',              // Ox Alpha Free
  baseUrl: 'https://opencode.ai/zen/v1',
  apiKey: 'public',
  fallbackModels: await discoverFreeModels()
});

Free Models & Dynamic Fallback

Web Agents query the OpenCode Zen endpoint GET /models at startup to dynamically discover which free models are available (ids ending in -free). The retry order always starts with Ox Alpha (x-preview-f-free), then Mimo (mimo-v2.5-free), followed by the remaining free models as reported by the API:

// Discover free models from OpenCode Zen, ordered by preference
async function discoverFreeModels() {
  const PREFERRED = ['x-preview-f-free', 'mimo-v2.5-free']; // Ox Alpha, Mimo
  const res = await fetch('https://opencode.ai/zen/v1/models', {
    headers: { 'Authorization': 'Bearer public' }
  });
  const { data } = await res.json();
  const free = data.map(m => m.id).filter(id => id.endsWith('-free'));
  // Preferred models first, remaining free models by availability
  return [
    ...PREFERRED.filter(id => free.includes(id)),
    ...free.filter(id => !PREFERRED.includes(id))
  ];
}

If a request fails (rate limit, upstream error, timeout), the Agent automatically retries with the next model in the list.

// Run a task const result = await agent.run('Find all .prg files and summarize them'); console.log(result.content);

FiveWin TWebView2 Integration

Web Agents integrate natively with FiveWin's TWebView2 class, providing a full chat UI inside desktop applications:

#include "FiveWin.ch"

FUNCTION Main()
   LOCAL oWnd, oView
   DEFINE WINDOW oWnd TITLE "Agents - Web Agent"
   oView := TWebView2():New( oWnd )
   oView:Navigate( "agents/web/index.html" )
   ACTIVATE WINDOW oWnd CENTERED
RETURN NIL

AI Disk Classifier

Web Agents include an AI disk classifier powered by transformers.js — classify files on disk using local AI models without sending data to any cloud service.

// Classify files on disk
const result = await agent.run(
  'Classify all files in c:\\projects by type (source, config, doc, asset)'
);
